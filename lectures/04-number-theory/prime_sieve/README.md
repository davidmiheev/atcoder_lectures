# Prime Sieves

Difficulty: 3/9 · Category: Number Theory

Original notes on sieving: the sieve of Eratosthenes and its
O(N log log N) bound via Mertens' theorem, the smallest-prime-factor table
and O(log n) factorization, the O(N) linear sieve, bulk evaluation of
multiplicative functions (divisor count, divisor sum, Euler totient), and
the segmented sieve for primes in a narrow window with R up to ~1e12.

See [`notes.pdf`](notes.pdf) / [`notes.tex`](notes.tex), with reference
implementations in [`example.rs`](example.rs) and [`example.py`](example.py)
— both cover all five techniques and print matching output.
