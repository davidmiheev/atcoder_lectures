# Sparse Table

Difficulty: 3/9 · Category: Data Structures

Original notes on the sparse table: an O(n log n)-build, O(1)-query
structure for range queries under an idempotent operator (min, max, gcd,
AND, OR). See [`notes.pdf`](notes.pdf) / [`notes.tex`](notes.tex), with
reference implementations in [`example.rs`](example.rs) and
[`example.py`](example.py).
